# OmicsFusion demo dataset

A synthetic case/control (`treated` vs `control`) multi-omics study with
40 samples, generated by `generate_demo_data.py` (fixed seed, reproducible).

| File | Modality | Shape (features x samples) |
|---|---|---|
| `transcriptomics.csv` | RNA-seq counts | 300 x 40 |
| `proteomics.csv` | Protein intensities | 150 x 40 |
| `metabolomics.csv` | Metabolite abundances | 80 x 40 |
| `metadata.csv` | Sample metadata (condition, batch, sex, age, tissue, timepoint) | 40 rows |

The first 20 features of each omics layer carry a simulated `treated`-vs-`control`
effect; the rest are noise. This gives the demo differential analysis,
integration, and ML modules a real (if synthetic) signal to recover.

## Run the full pipeline

```bash
pip install -e .
omicsfusion run --config examples/demo/config.yaml
```

Results (QC JSON, normalized matrices, differential tables, integration
matrices, ML metrics, and `report.html`) are written to
`examples/demo/results/`.

## Regenerate the data

```bash
python examples/demo/generate_demo_data.py
```
